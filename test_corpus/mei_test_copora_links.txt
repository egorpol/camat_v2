# MEI test corpus — raw GitHub links to .mei (and MEI-as-.xml) files.
# Sorted by encoding project. Rechecked 2026-08-15: original URLs return HTTP 200.
# Preference: complete works / complete movements. Skip incipits, voice-part
# extracts, measure-position stubs, expanded/OMR duplicates, and demo files.
#
# No usable raw-GitHub complete-work MEI corpus (yet):
#   - Measuring Polyphony mp-music-files: Sibelius/MusicXML only (MEI lives in
#     MeasuringPolyphony/measuring_polyphony_jekyll)
#   - Digital Mozart Edition / DIME: served from dme.mozarteum.at, not GitHub
#   - ELVIS-Project mass-duos-corpus-josquin-larue: MusicXML/krn/MIDI/Sibelius
#   - Lost Voices / Du Chemin: MEI on digitalduchemin.org, not a GitHub tree
#   - WeGA / Weber clarinet quintet: Zenodo / Paderborn GitLab, not GitHub
#   - DCM Nielsen catalogues and Corpus monodicum: metadata or editor, not scores
#   - annakijas1/rebalancing-music-canon: MEI incipits, not complete works
#   - DDMAL/mei-test-set complete-examples: overlap sample-encodings; other
#     folders are feature snippets rather than complete works
#   - Music DH catalogue: a discovery layer, not a corpus
#
# Intentionally omitted even though present in the source repos:
#   - music-encoding/sample-encodings: header-only files, docStarts, and
#     Complete_examples duplicated under older MEI versions (a few older-schema
#     complete examples are kept for coverage)
#   - SEILSdataset: remaining 145 particella files (single-voice copies of the
#     choral set; Marenzio's five voices are kept as a sample of that type)
#   - Freischuetz-Digital/data-music: ready-for-use source_abbr/expan/raw
#     derivatives, measure concordance, and annotation extracts
#   - BeethovensWerkstatt/data: data/module2/works/test.mei
#   - marenzio/marenzio.github.io: M_01_5_07_Che_fa_oggi_il_mio_sole-demo.mei
#   - TROMPA: tiny work-level wrappers, *-expanded.mei, OMR/facsimile variants,
#     default.mei / minimal.mei, and measure_annotations.mei
#   - CRIM: mass-head files without musical content, plus pieces CRIM flags as
#     incomplete (see comments in the CRIM section)
#   - Beggar's Opera: MEI3.0.0 duplicates of mei/, plus *_endings.mei
#   - Measuring Polyphony: assets/parts (part extracts)
