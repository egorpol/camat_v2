# Presentations

Conference posters and talks for CAMAT. Each event lives in a `YYYY-venue`
folder with a short README (title, venue, authors, links) and the finished
artifact (usually a PDF).

Working drafts stay outside this tree. Prefer Zenodo or a similar archive for multi-megabyte
PDFs, and link them from the event README instead of committing large binaries.
