# CAMAT development archive

This directory preserves earlier implementations, maintainer probes, and
experiments, including the introductory notebooks in `basics_tutorials/`.
Saved outputs are retained as historical examples.

For current tutorials, use the [notebook roadmap](../docs/notebooks.md) and
the notebooks in [`notebooks/`](../notebooks).

Archived code may depend on local paths, older APIs, external datasets, or
maintainer-specific tools. Some probes rewrite edition files. Review their
configuration and use copies of source data before running them.

The archive is not included in the PyPI wheel or source distribution. Keeping
outputs here preserves the development record and also keeps its checkout
size; moving a notebook here does not remove its data from Git history.
