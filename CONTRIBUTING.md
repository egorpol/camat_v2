# Contributing to CAMAT

Bug reports, documentation improvements, and focused pull requests are welcome.
Use [GitHub Issues](https://github.com/egorpol/camat_v2/issues) for reproducible
bugs and feature proposals.

See the [contributor guide](docs/contributing.md) for environment setup,
tests, documentation previews, and notebook conventions. See
[release testing](docs/releasing.md) for the supported Python matrix and
publishing checks.
