# Timeline MEI exports

These are retained development outputs from timeline-to-MEI conversion,
including examples associated with “Lose Yourself” and “In da Club”. They are
not part of the supported notebook sequence or the PyPI distributions.

Before public release, record the source dataset and version, the source URL,
and the reuse terms or permission covering both the input and derived MEI.
Those terms have not yet been established here. Conversion does not grant new
rights to the underlying music, text, or encoding.

For reproducible converter tests, use the synthetic timeline in
[`tests/release/test_installed_package.py`](../../tests/release/test_installed_package.py).
