# About CAMAT

CAMAT is developed by Egor Polyakov. Its editorial tools grew out of work on
the [edition corpora](guides/edition-corpora.md).

## Funding

CAMAT is funded by the German Research Foundation (DFG), programme
Library and Information Services — E-Research Technologies (LIS), grant
PF 669/18-1.

## Citation

If you use CAMAT in research, cite the software and state the version used.
[CITATION.cff](../CITATION.cff) supplies machine-readable citation metadata;
GitHub exposes it through **Cite this repository**. Published versions and
their dates are listed in [the releases](https://github.com/egorpol/camat_v2/releases).
